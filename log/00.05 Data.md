## 1. Source Data

**[SPEC]**
- **Repository:** `https://github.com/BetimShala/mburoja-api`
- **Main Data File:** `invocations.json`
- **Raw JSON URL:** `https://raw.githubusercontent.com/BetimShala/mburoja-api/master/invocations.json`
- **Audio Base URL:** `https://raw.githubusercontent.com/BetimShala/mburoja-api/master/audios/`

**[NOTE]**
We are inheriting a mature dataset of Dzikr and Dua with Arabic, Latin (transliteration), and Albanian translations.

---

## 2. Data Structure

**[SPEC]**
The data is a nested array: `Chapter[]` containing `Invocation[]`.

```typescript
interface Invocation {
  id: string;      // ID within chapter (e.g. "01")
  audio: string;   // Path (e.g. "/audios/001_01.mp3")
  arabic: string;
  latin: string;
  albanian: string;
  reference: string;
}

interface Chapter {
  id: string;           // Chapter ID (e.g. "1")
  chapter_name: string; // e.g. "1. Çfarë duhet thënë..."
  invocations: Invocation[];
}
```

---

## 3. Integration Strategy

**[SPEC]**
1. **Local Storage:** Save a copy of `invocations.json` to `src/data/invocations.json`.
2. **Type Safety:** Define the `Invocation` and `Chapter` types in `src/types/data.ts`.
3. **Data Access:** Create a `src/lib/data.ts` utility to:
   - Provide `getChapters()`: Returns all chapters.
   - Provide `getInvocationById(chapterId, invocationId)`: Direct access for routing.
4. **Audio Mapping:**
   - Prepend `https://raw.githubusercontent.com/BetimShala/mburoja-api/master` to the `audio` field to get the absolute streaming URL.

**[NOTE]**
Streaming directly from GitHub Raw avoids hosting costs and large initial bundle sizes. Since the file structure is stable, this is a highly efficient way to build the MVP.
