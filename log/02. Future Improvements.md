# Future Improvements & Roadmap

## 🎨 UI/UX Enhancements
- **Theming System**: Implement a robust Light/Dark mode toggle.
  - **Dark Mode**: Maintain the "Midnight Sanctuary" aesthetic.
  - **Light Mode**: Use a "Morning Glow" theme with warm, soft creams and sage greens.
- **Micro-interactions**: Add subtle animations for play/pause transitions and list item hovers.
- **Accessibility**: Ensure full WCAG compliance for screen readers and keyboard navigation.

## 🎵 Audio & Media
- **Alternative Audio Sources**: Integrate audio from [HisnMuslim.com](https://hisnmuslim.com/i/en/1) as a high-quality alternative or fallback.
- **Audio Speed Control**: Allow users to adjust playback speed (0.75x, 1x, 1.25x, 1.5x).
- **Background Playback**: Improve mobile experience with better Lock Screen media controls.

## 📊 Data & Content
- **Translation Expansion**: Support more languages (Albanian was the original, English is now standard).
- **Favorites & Playlists**: Allow users to create custom Adhkar collections.
- **Daily Reminders**: Implement browser notifications for morning and evening Adhkar times.
- **Reference Links**: Link individual invocations directly to their sources on HisnMuslim.com for deeper study.

## 🛠 Technical
- **Offline Support**: Implement Service Workers for full PWA (Progressive Web App) capabilities.
- **Analytics**: Add privacy-focused usage tracking to see which Adhkar are most popular.
- **Optimization**: Further optimize Orama search indexing for even faster performance.
