# Planning for Future Features

Bismillah.

This report outlines the next phase of development for the Dzikr & Dua application, focusing on text analysis, animations, user settings, and content discovery.

## Proposed Features (2026-05-15)

1.  **Arabic Matan Highlighting**:
    - **Goal**: Refine the display of Arabic text to specifically highlight the *matan* (the core text) while potentially de-emphasizing surrounding text (like "Bismillah" or reference markers).
    - **Implementation**: Analyze `invocations.json` structure for Arabic text. Update rendering logic in `DzikrCard` (or equivalent) to apply specific styles to the matan part.

2.  **MP3 Download Animation**:
    - **Goal**: Provide a premium visual experience when an audio file is being fetched/buffered.
    - **Implementation**: Add a sleek animation (possibly using `framer-motion`) to the buffering progress bar in `AudioPlayer.tsx`. Use a glowing or pulsing effect to indicate active download.

3.  **Display Settings (Theme, Translation, Transliteration)**:
    - **Goal**: Allow users to customize their reading experience.
    - **Implementation**:
        - Update `usePlayerStore.ts` to include `showTranslation`, `showTransliteration`, and `theme` preferences.
        - Integrate these toggles into the Settings menu in `play.tsx`.
        - Conditionally render translation and transliteration blocks in the UI based on these settings.

4.  **Enriched Suggestion Playlists**:
    - **Goal**: Increase user engagement by providing curated entry points.
    - **Implementation**: - Add "Evening Adhkar" and "Road Trip" playlists.
    - Implement "Library/Browse" view for full content navigation.

5.  **Browse Feature**:
    - **Goal**: Provide a comprehensive library view for users to explore the entire dataset without needing to search.
    - **Implementation**: Add a "Library" or "Browse" tab/view that lists all available chapters and categories, providing a structured way to navigate the data.

6. **Getting more audio source**:
    - Include dhikr and ayat from famous reciters.
    - Integrate more audio versions for each Dhikr/Dua.
    - Fetch Ayat-specific audio from famous reciters (e.g., Al-Quran.cloud API).

7. **Change audio change button from icon to text initial**:
    - Change the button from an icon to the text initial of the audio.
    - This allows users to see which one is playing without having to click.

## Implementation Strategy

- **Phase 1**: Update Store and Settings UI to handle new preferences.
- **Phase 2**: Refine Arabic text rendering logic.
- **Phase 3**: Implement animations and visual polish.
- **Phase 4**: Add new playlists and the Browse view.

InsyaAllah, these changes will make the app more personalized and easier to navigate.

Alhamdulillah.
