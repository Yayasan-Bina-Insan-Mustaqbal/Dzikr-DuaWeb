# Planning for Future Features

Bismillah.

This report outlines the next phase of development for the Dzikr & Dua application, focusing on text analysis, animations, user settings, and content discovery.

## Proposed Features (2026-05-15)

1.  **Arabic Matan Highlighting**:
    - **Goal**: Refine the display of Arabic text to specifically highlight the *matan* (the core text) while potentially de-emphasizing surrounding text (like "Bismillah" or reference markers).
    - **Status**: **DONE** (2026-05-15)
    - **Implementation**: `formatArabic` function in `play.tsx` uses regex to de-emphasize parentheses and brackets while applying a `matan` class to the core text.
    - **How to check**: Play any Dzikr that has text in brackets (e.g., "Upon Waking Up (1)"). Notice the brackets are dimmed (opacity-30) while the main text is vivid.

2.  **MP3 Download Animation**:
    - **Goal**: Provide a premium visual experience when an audio file is being fetched/buffered.
    - **Status**: **DONE** (2026-05-15)
    - **Implementation**: Added a `motion.div` to the progress scrubber in `play.tsx` that pulses using `framer-motion` to indicate buffering progress.
    - **How to check**: Play a track on a slower connection (or watch carefully as it loads). The light progress bar representing buffered data now has a subtle pulsing opacity animation.

3.  **Display Settings (Theme, Translation, Transliteration)**:
    - **Goal**: Allow users to customize their reading experience.
    - **Status**: **DONE** (2026-05-15)
    - **Implementation**:
        - Updated `audio.ts` store with `showTranslation`, `showTransliteration`, and `theme` states.
        - Integrated toggles and a theme selector into the Settings dropdown (more_vert icon) in `play.tsx`.
    - **How to check**: Click the three-dot "Settings" icon in the top right. Toggle Translation or Transliteration to see text disappear/reappear. Use the Theme menu to switch between Dark, Light, Sepia, and Emerald.

4.  **Enriched Suggestion Playlists**:
    - **Goal**: Increase user engagement by providing curated entry points.
    - **Status**: **DONE** (2026-05-15)
    - **Implementation**: `defaultSuggestions` in `play.tsx` now explicitly searches for and presents "Morning Adhkar", "Evening Adhkar", and "Travel" playlists.
    - **How to check**: Open the Search/Browse sidebar when the queue is empty. You will see these curated playlists under "Suggested Playlists".

5.  **Browse Feature**:
    - **Goal**: Provide a comprehensive library view for users to explore the entire dataset without needing to search.
    - **Status**: **DONE** (2026-05-15)
    - **Implementation**: Added a "Browse" mode to the right sidebar that lists all available chapters with their Dua counts.
    - **How to check**: In the Search/Browse sidebar, click the "Browse" tab (or click the search icon if no search is active). Scroll through the full list of chapters.

6. **Getting more audio source**:
    - **Goal**: Include dhikr and ayat from famous reciters and integrate more audio versions.
    - **Status**: **DONE** (2026-05-15)
    - **Implementation**: `audio_versions` support added to `Invocation` type and `audio.ts` store. The player now handles switching between 'default', 'rodja', and 'mburoja-api' sources.
    - **How to check**: Play a Dzikr that has multiple versions (like Morning Adhkar). Use the version toggle button (initially 'D') in the player controls to switch reciters.

7. **Change audio change button from icon to text initial**:
    - **Goal**: Change the button from an icon to the text initial of the audio.
    - **Status**: **DONE** (2026-05-15)
    - **Implementation**: The version toggle button now dynamically displays 'D' for Default, 'R' for Rodja, 'M' for Mburoja, etc., based on the current selection.
    - **How to check**: Look at the button next to the skip-previous control. It shows a letter representing the active audio source instead of a generic icon.

## Implementation Strategy

- **Phase 1**: Update Store and Settings UI to handle new preferences.
- **Phase 2**: Refine Arabic text rendering logic.
- **Phase 3**: Implement animations and visual polish.
- **Phase 4**: Add new playlists and the Browse view.

InsyaAllah, these changes will make the app more personalized and easier to navigate.

Alhamdulillah.
